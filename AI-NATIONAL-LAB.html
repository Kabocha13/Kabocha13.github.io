よくある質問

生成が失敗する・通信エラーが出る

インターネット接続を確認し、アプリを再起動してから再試行してください。改善しない場合は、発生した画面と操作手順を添えてメールでお問い合わせください。

購入した生成回数が反映されない

App Store の購入情報をサーバーで検証した後に付与されます。しばらく待っても反映されない場合は、購入日時と App Store の取引情報を添えてメールでご連絡ください。返金は Apple の規定に従います。

広告を非表示にしたい

生成回数の追加購入と任意支援の累計が500円以上の場合、バナー広告とインタースティシャル広告は非表示になります（リワード広告は除く）。

データを削除したい

端末内のデータはアプリを削除することで消去できます。サーバーに保存された公開SNS投稿等の削除は、メールでご依頼ください。

未成年でも使えますか？

保護者の同意と管理のもとでご利用ください。個人情報、学校名、住所、連絡先などは入力しないでください。

プライバシーポリシー

制定日: 2026年6月29日　最終改定日: 2026年7月13日

1. アプリ名・運営者

アプリ名: こっからぼ 運営者: IssaShimoda 問い合わせ先: ishimoda.issa@gmail.com

2. 収集する情報

このアプリは、ユーザーが入力した政策文、国家名、国家設定、生成結果、政策履歴、アプリ設定、通報内容、不具合報告、要望、任意で入力された返信先メールアドレスを取り扱います。不具合報告や要望の送信時には、調査のためにアプリ版、ビルド番号、OS、端末種別、言語設定、選択中の国家ID、国家名、年数、ターン数を送信することがあります。広告配信のため、Google AdMob が端末情報、IPアドレス、広告識別子、広告表示や操作に関する情報、診断情報を処理することがあります。アカウント登録機能は現在提供していませんが、不正利用防止と保存データの所有確認のため、Supabase Auth による匿名認証IDを発行します。 生成回数の購入または任意支援を行う場合、注文内容(注文種別、金額、購入回数)、注文状態、App Store 取引ID、匿名認証IDを運営者側サーバー(Supabase)に保存します。クレジットカード番号などの決済情報は Apple が直接取り扱い、運営者のサーバーには保存されません。 SNS公開機能を利用する場合、公開を選んだ投稿の本文、アカウント表示名、ハッシュタグ、国家名、ターン情報、匿名認証ID、ハート等のリアクション、通報内容、投稿者の非表示設定をサーバーに保存します。公開していない投稿は他のユーザーへ共有されません。

3. 収集しない情報

このアプリは、端末の正確な位置情報、連絡先、カメラ、マイク、カレンダー、ヘルスケア情報を意図的に収集しません。写真ライブラリについては、ユーザーがシェアカード等を写真アプリへ保存する操作をしたときに限り、端末側で保存書き込みを行います。アプリが写真ライブラリの内容を読み取ったり、サーバーへ送信したりすることはありません。クレジットカード番号等のカード情報は運営者が取得・保存しません。

4. 利用目的

取得した情報は、AIによる国家史・新聞・画像生成、国家データの保存と表示、公開SNSフィードの提供、リアクション処理、通報確認、広告配信、不具合対応、問い合わせ対応、品質改善、悪用防止、利用状況の把握、サービス運営のために利用します。

5. 第三者AIサービスへの送信

政策入力、生成に必要な国家情報、履歴の一部、安全確認に必要な文脈は、Supabase Edge Function を通じて OpenAI API 等の第三者AIサービスへ送信されることがあります。OpenAI APIキーはアプリ内には保存しません。個人情報、秘密情報、他人の情報、公開したくない内容は入力しないでください。

6. 第三者提供・外部委託

取得した情報は、Supabase、OpenAI API、Google AdMob 等、サービス提供に必要な外部サービスへ処理を委託する場合があります。法令に基づく場合、不正利用や安全上の問題に対応する場合、運営上必要な範囲で委託する場合を除き、取得した情報を第三者に販売しません。 ユーザーがSNSへ公開した投稿は、他のアプリ利用者から閲覧されることがあります。公開前に内容を確認してください。

7. 保存期間

端末内の国家データと設定は、ユーザーが削除するかアプリを削除するまで保存されます。Supabase に保存される生成履歴、公開SNS投稿、リアクション、通報、非表示設定、不具合報告、要望は、調査、運営、品質改善に必要な期間保存します。不要になった情報は、運営判断により削除または匿名化することがあります。公開を取り下げた投稿は、他のユーザーのフィードから外れます。

8. 削除・開示・訂正

保存データの削除、開示、訂正を希望する場合は、ishimoda.issa@gmail.com へ連絡してください。本人確認と対象データの特定ができる範囲で対応します。端末内データはアプリ削除により削除できます。公開SNS投稿の削除や通報対応についても同窓口で受け付けます。

9. 未成年の利用

未成年者が利用する場合は、保護者の同意と管理のもとで利用してください。個人情報、学校名、住所、連絡先などを入力しないでください。

10. セキュリティ対策

APIキーはアプリ内に保存せず、通信は Supabase を経由します。保存先ではアクセス制御を行います。ただし、通信や保存の安全性を完全に保証するものではありません。

11. 変更

プライバシーポリシーを変更する場合、アプリ内表示の更新や再同意の要求により通知します。重要な変更がある場合は再同意を求めます。

12. 問い合わせ

プライバシーに関する問い合わせは、ishimoda.issa@gmail.com へ送ってください。

第三者AI利用への同意

制定日: 2026年6月29日

1. 送信先

このアプリは、政策シミュレーション結果、新聞本文、社会面画像、SNS投稿本文・画像、安全確認を生成するため、Supabase Edge Function を通じて OpenAI API 等の第三者AIサービスへ情報を送信します。現時点では Gemini API など他の第三者AIサービスは利用していません。将来利用先を追加する場合は、必要に応じて同意内容を更新します。

2. 送信する内容

ユーザーが入力した政策文、国家名、人口、現在の国家状態、過去の政策履歴や生成結果の一部、安全確認に必要な文脈を送信することがあります。不具合調査や通報対応では、通報された生成結果や関連情報を確認することがあります。

3. 利用目的

送信した情報は、架空国家の政策シミュレーション、新聞生成、画像生成、安全確認、不適切出力の低減、品質改善、不具合調査のために利用します。

4. 入力してはいけない情報

個人情報、住所、電話番号、メールアドレス、学校名、勤務先、秘密情報、他人の情報、公開したくない内容、犯罪・暴力・差別・自傷・性的搾取を助長する内容を政策文に入力しないでください。

5. 同意しない場合

第三者AI利用に同意しない場合、AI生成を前提とするこのアプリの主要機能を利用できないため、プレイできません。

6. 同意記録

アプリは、第三者AI利用への同意状態、同意日時、同意バージョンを端末内のv3セーブデータに保存します。同意内容を重要変更する場合、再同意を求めることがあります。

7. AI生成結果の注意

このアプリは架空国家のシミュレーションであり、現実の政治・経済・法律判断ではありません。AIの生成結果について、正確性、安全性、有用性、完全性を保証しません。
